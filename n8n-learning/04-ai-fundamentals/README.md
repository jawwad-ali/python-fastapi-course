# 04 — AI Fundamentals

This is where AI enters the course, and it starts from zero. You do not need any
machine learning background.

The most important idea in this module is the difference between an LLM and an
AI agent, because almost everything confusing about AI automation comes from
mixing those two up.

> **`LLM != AI Agent`**
>
> An **LLM** is a text-in, text-out model. You give it words, it gives you words
> back, and then it is finished. It cannot do anything else.
>
> An **AI agent** is an LLM plus tools plus a loop. It can decide to call a tool,
> look at the result, and decide what to do next — over and over — until the job
> is done.
>
> This module is only about the LLM. Agents come in module 06. Learn the simple
> thing first, or agents will feel like magic instead of engineering.

## 🎯 Learning Objectives

- Explain in plain words what a large language model does and does not do
- Write a prompt that gives you the same useful answer every time
- Call a chat model from an n8n workflow
- Get back clean JSON instead of a paragraph, so the next node can use it
- Explain what an embedding is and why it is needed for search
- Put an LLM in the middle of a real workflow, not just a test

## 🧠 What You Will Learn

- **LLM basics** — what a large language model is, why it sometimes makes things
  up, and what it is genuinely good at
- **Prompting** — instructions, examples, and giving the model the context it
  needs to answer well
- **Chat models** — system messages versus user messages, and what "temperature"
  changes
- **Structured output** — forcing the model to answer in a fixed JSON shape so a
  workflow can rely on it
- **AI nodes in n8n** — which node to reach for, and how a model is attached to it
- **Embeddings concept** — turning text into numbers that capture its meaning, so
  a computer can find "similar" text (this is the foundation of module 05)
- **A basic AI workflow** — data in, model in the middle, useful action out

# 07 — Tools and Databases

An agent that can only talk is a demo. An agent that can read your database, send
the email, and update the CRM record is a product.

This module connects your workflows and agents to real systems — and teaches you
to do it safely, because the same connection that lets an agent read a table also
lets it change one.

## 🎯 Learning Objectives

- Connect n8n to a real database and run queries from a workflow
- Write queries that cannot be broken by unexpected input
- Give an agent database access without giving it permission to destroy data
- Send email and Slack messages from a workflow
- Read from and write to CRM-style systems
- Wrap any custom API of your own as a tool an agent can call

## 🧠 What You Will Learn

- **PostgreSQL** — connecting, querying, inserting, and updating
- **MySQL** — the same, and what differs
- **Database queries** — parameters instead of pasted-together strings, and why
  that difference matters enormously when an LLM is writing the input
- **APIs** — calling services that have no dedicated n8n node
- **Email** — sending mail from a workflow, and reading a mailbox as a trigger
- **Slack** — messages, channels, and replying in a thread
- **CRM-style systems** — the shape almost all of them share: contacts, deals,
  notes, and how to sync them without creating duplicates
- **Custom APIs** — exposing your own service so an agent can use it as a tool
- **Read-only by default** — the habit of giving each connection the smallest
  permission that still does the job

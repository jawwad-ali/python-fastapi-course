# 01 — Workflow Basics

Now that n8n runs, this module is about building. You will learn the small set of
ideas that every workflow, simple or huge, is made of.

## 🎯 Learning Objectives

- Choose the right trigger for the job you want to automate
- Connect nodes so data flows from one to the next in the order you intend
- Predict what a workflow will do before you run it
- Read an execution and see exactly what each node received and returned
- Send a workflow down two different paths depending on the data

## 🧠 What You Will Learn

- **Triggers** — manual, on a schedule, and "when something happens elsewhere"
- **Nodes** — how a node takes input, does one job, and produces output
- **Connections** — the lines between nodes, and what they actually carry
- **Workflow execution** — the difference between testing a single node, testing
  the whole workflow, and a workflow running on its own
- **Expressions** — a first look at pulling a value out of the previous node
  instead of typing it by hand
- **Basic branching** — making a decision in the middle of a workflow
- **Workflow thinking** — breaking a task you do manually into steps a machine can
  follow

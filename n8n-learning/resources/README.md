# Resources

Shared material used across more than one module — so it lives here instead of
being repeated or going stale in three places.

## What goes here

- **Glossary** — the terms used in this course, each explained in one or two
  plain sentences
- **Cheat sheets** — expression syntax, common node settings, HTTP status codes
- **Sample data** — small files to practise on, so lessons do not depend on an
  outside API staying online
- **Links** — official n8n documentation, community forum, and anything worth
  reading
- **Troubleshooting** — the errors beginners hit most often, and the fix for each

## What does not go here

Lesson content. If something belongs to one module, it belongs in that module's
folder.

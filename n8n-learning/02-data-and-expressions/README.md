# 02 — Data and Expressions

This is the module that decides whether the rest of the course feels easy or
painful. Almost every problem beginners hit in n8n is really a data problem: the
value is there, but not in the shape the next node wants.

Take your time here. APIs, RAG and AI agents all depend on it.

## 🎯 Learning Objectives

- Read a block of JSON and say what is an object, what is an array, and what is a
  single value
- Explain how n8n passes data between nodes as a list of items
- Pull any value out of previous data using an expression
- Reshape data: rename fields, drop fields, build new ones
- Remove the items you do not want before they reach the next node
- Use the Code node when the built-in nodes cannot do what you need

## 🧠 What You Will Learn

- **JSON** — the format almost every API and every n8n node speaks
- **Objects** — data stored as named fields, like `{ "name": "Ali" }`
- **Arrays** — an ordered list of values, like `["apple", "banana"]`
- **Items** — n8n does not pass one object between nodes, it passes a *list* of
  them, and that is the single most common thing beginners misunderstand
- **Mapping data** — connecting a field from an earlier node to an input later on
- **Expressions** — the `{{ }}` syntax for reading and combining values
- **Set / Edit Fields** — the node you will use more than any other
- **Filtering** — keeping only the items that matter
- **Transforming data** — splitting, combining, sorting, and grouping
- **Basic Code node usage** — a few lines of JavaScript or Python for the cases
  where no node fits
